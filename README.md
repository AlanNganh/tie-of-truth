# Tie of Truth — Ryan Vo profile

A responsive, static demonstration profile. Open `index.html` directly or serve this folder with any static web server; no build step is required.

## Publishing and QR code

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes this folder to GitHub Pages. The QR card is configured for `https://alann.github.io/tie-of-truth/` and generates a high-contrast PNG with a white quiet zone that links directly to the profile.

The QR download is enabled on the published profile. It is intentionally disabled on local file and preview URLs so those temporary addresses are not encoded into the QR code.

The contact and social links are demonstration placeholders and should be updated before using the profile publicly.
